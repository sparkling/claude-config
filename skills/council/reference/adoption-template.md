# Linked Data Council — Adoption Record (template)

Per [methodology.md §Adoption hooks](methodology.md), this record declares the project-specific
context for a project's adoption of the Linked Data Council methodology. The methodology body
itself is portable; this record fills its declared slots. **Copy this file into your project**
(e.g. `<project>/<council-directory>/adoption.md`) and fill in each slot. A project whose adoption
record is missing a required slot is non-conforming.

- **Project:** <project name + one-line description>
- **Adopting date:** <YYYY-MM-DD>
- **Methodology version:** carried by the `council` skill (`reference/methodology.md`)
